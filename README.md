## Features

### AI Dictionary
Search any English word and instantly get IPA transcription, definitions, usage examples, synonyms, and thematic tags — all generated by Groq LLM.

### Translation
Translate between English and Russian powered by Groq AI. Translations are cached so repeated lookups are instant.

### Flashcards & Decks
Create vocabulary cards with translations, transcriptions, and examples. Organize them into color-coded decks with tags. Switch between grid and table views.

### Study Modes
- **Deck Study** — study cards from a specific deck, flip through them and mark as "Got it" or "Again"
- **Daily Mix** — a curated set of 10 cards picked daily from your entire collection, prioritizing newer and less-studied words

Progress is tracked per card: last studied date, correct/incorrect counts.

### Word of the Day
A new word appears every day in the sidebar — with pronunciation, translation, and a one-click save to your collection.

### Authentication
Email/password registration with verification, Google OAuth, password reset via email. Sessions use JWT with secure HttpOnly cookies.

### Dark Mode & Responsive UI
Full dark/light theme support. Desktop sidebar navigation, mobile bottom nav. Smooth animations with Framer Motion.

## Getting Started

### Prerequisites

- Go 1.23+
- Node.js 20+
- PostgreSQL
- API keys: [Groq](https://console.groq.com/), [Resend](https://resend.com/) (optional, for emails)

### Backend

```bash
cd backend
cp .env.example .env   # fill in your credentials
make migrate-up        # apply database migrations
make run               # start the API server on :8080
```

### Frontend

```bash
cd frontend
npm ci
npm run dev            # start dev server on :3000
```

The frontend proxies `/api/*` requests to the backend at `localhost:8080`.

## Configuration

Backend environment variables (see `backend/.env.example`):

| Variable               | Description                          |
|------------------------|--------------------------------------|
| `PORT`                 | Server port (default: 8080)          |
| `DATABASE_URL`         | PostgreSQL connection string         |
| `GROQ_API_KEY`         | Groq API key for dictionary & translation |
| `JWT_SECRET`           | JWT signing secret (min 32 chars)    |
| `GOOGLE_CLIENT_ID`     | Google OAuth client ID               |
| `GOOGLE_CLIENT_SECRET` | Google OAuth client secret           |
| `GOOGLE_REDIRECT_URL`  | Google OAuth redirect URL            |
| `RESEND_API_KEY`       | Resend API key for emails            |
| `EMAIL_FROM`           | Sender address for emails            |
| `APP_URL`              | Application URL for email links      |
